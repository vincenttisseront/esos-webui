# ESOS WebUI — Internationalization

## Locales

- **Default**: `fr` (`nuxt.config.ts`, `strategy: 'no_prefix'`)
- **Files**: [`i18n/locales/fr.json`](../i18n/locales/fr.json), [`i18n/locales/en.json`](../i18n/locales/en.json)
- **Parity**: [`tests/i18n-parity.test.ts`](../tests/i18n-parity.test.ts) — same keys, non-empty values

## Usage in Vue

```ts
const { t, tWithFallback, tError } = useEsosI18n()
t('nav.items.dashboard')
tWithFallback('common.actions.save', 'Enregistrer') // migration only
tError(err) // resolves errors.<data.code> when present
```

New UI copy **must** use `t('namespace.key')`. Do not add hardcoded French/English in templates.

## Namespace map

| Logical area | JSON prefix | Notes |
|--------------|-------------|--------|
| Shared chrome | `common.*` | Actions, copy, close |
| Auth / login | `auth.*`, `errors.auth.*`, `errors.oidc.*` | |
| SSH status | `ssh.status.*` | Header badge |
| System config (SAN) | `admin.sysconfig.*` | Network, SMTP, users, hostname, system |
| RAID | `raid.*` | Keep top-level (≈ storage.raid) |
| LVM | `lvm.*` | |
| Filesystems / SCST targets | `storage.*` | `storage.targets`, FS wizards |
| Cluster HA | `cluster.*` | |
| Administration | `admin.*` | SAN list, users, providers |
| API errors | `errors.*` | Match `data.code` from server |
| Terminal WS | `terminal.ws.*` | |

## Do not translate

Shell commands, `/dev/*` paths, WWPN/IQN, RAID levels (`raid0`, `raid5`, …), SCST handler names, package names, raw PCI paths, controller CLI output.

## Server error codes

Additive contract: keep `message` / `statusMessage` for logs and legacy clients; add `data: { code }` when possible.

Inventory: [`server/utils/i18n-error-codes.ts`](../server/utils/i18n-error-codes.ts).  
Locale keys: `errors.<dotted.code>` (e.g. `errors.lvm.scst_device_conflict` → `errors.lvm.scst_device_conflict` in JSON nesting).
